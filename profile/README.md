# GetSetKeys

Client access for web and app agencies: [getsetkeys.com](https://getsetkeys.com)

If an agency sent you a GetSetKeys setup link, GitHub may be one of its steps. You install the GetSetKeys app on the repositories you pick, and it invites the agency's GitHub account to those repositories with the role the agency asked for. Then it revokes your sign-in and uninstalls itself, so nothing stays connected to your account. To remove the agency later, open the repository's Settings, then Collaborators (Collaborators and teams on an organization's repository).
